# 🛒 Advanced E-Commerce Admin Dashboard

A modern and responsive **E-Commerce Admin Dashboard** built using **HTML, CSS, and Python Flask**. This project provides an admin interface to monitor sales, manage products and inventory, track orders, and view important business statistics.

## 🚀 Features

* 📊 **Dashboard Overview**

  * Total revenue
  * Total orders
  * Total customers
  * Products sold
  * Revenue overview
  * Sales by category

* 📦 **Product Management**

  * View products
  * Add new products
  * Manage product prices
  * Track inventory/stock
  * Product status monitoring

* 🧾 **Order Management**

  * View recent orders
  * Customer information
  * Order amount
  * Order date
  * Order status

* ⚙️ **Admin Settings**

  * Order notifications
  * Low-stock alerts
  * Weekly sales reports

* 📱 **Responsive Design**

  * Desktop-friendly dashboard
  * Tablet support
  * Mobile-responsive layout

* 🐍 **Python Flask Backend**

  * Flask routing
  * Server-side rendering with Jinja2
  * Form handling
  * Dynamic product management

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/rahulswain2005/E-commerce-Admin.git
```

### 2. Open the project folder

```bash
cd E-commerce-Admin
```

### 3. Install Flask

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000
```

## 📊 Dashboard Modules

### Dashboard

The main dashboard displays important business information such as:

* Revenue
* Orders
* Customers
* Products sold
* Revenue trends
* Category-wise sales
* Recent orders

### Products

The product management section allows the admin to:

* Add new products
* Select product categories
* Set product prices
* Update stock quantities
* Monitor product status

### Orders

The order section provides information about:

* Order ID
* Customer
* Product
* Amount
* Order date
* Delivery/processing status

### Settings

The settings section provides basic admin configuration options such as notifications and inventory alerts.

## 🎯 Project Objective

The main objective of this project is to build a practical **e-commerce administration system** that helps store administrators monitor business performance and manage products and orders through a centralized dashboard.

This project also demonstrates practical knowledge of **frontend development, Python Flask, server-side rendering, routing, forms, and responsive UI design**.
